# AIAM

Material de estudio del curso **AI Agent Manager (AIAM™)** de Certiprof: el curso convertido en prosa para escucharlo con un lector text-to-speech, material de repaso y un proyecto de agente de IA construido según las reglas del curso.

## Por dónde empezar

**[`estudio/indice.md`](estudio/indice.md)** es el mapa de todo el material: por módulo y por tema, con enlaces a la sección exacta de cada archivo. Lo genera `estudio/scripts/generar-indice.py`.

## Qué hay en el repositorio

| Carpeta o archivo | Contenido |
|---|---|
| `certiprof-ai-agent-manager-aiam-guia-de-autoestudio-es.pdf` | la guía original del curso (97 páginas, 5 módulos) |
| `estudio/modulos/` | el curso convertido en prosa para escuchar, un archivo por módulo |
| `estudio/resumenes/` | un resumen por módulo, para repasar en pocos minutos |
| `estudio/apuntes/` | apuntes visuales en PDF para imprimir |
| `estudio/glosario.md` y `estudio/preguntas-frecuentes.md` | los términos y las dudas que fueron surgiendo al estudiar |
| `estudio/diagramas.md` | diagramas Mermaid de temas del curso |
| `estudio/plantillas/` | 15 plantillas para aplicar el curso; empiece por `00-guia.md` |
| `estudio/proyecto-agente/agente-soporte-n1/` | un agente de soporte construido con las reglas del curso; su documentación empieza en `docs/README.md` |
| `AGENTS.md` | las reglas que sigue cualquier agente de IA que trabaje en este repositorio |
| `MEMORY.md` | la memoria del proyecto: decisiones, estado y pendientes |

## Cómo usarlo

1. Abrir el módulo que corresponda de `estudio/modulos/` en el lector text-to-speech.
2. Cuando aparezca un término o una duda, preguntarle al agente de IA: la respuesta queda en el glosario o en las preguntas frecuentes, con un largo pensado para escucharla en uno o dos minutos.

Qué se cambió respecto del PDF para que se lea bien en voz alta, y cómo se mantiene el repositorio, está en `AGENTS.md`.
