# Las facturas no se sincronizan

> Documento ficticio de ejemplo: Nubesoft y su producto, Nubesoft Facturación, no existen.

Aplica cuando las facturas emitidas en la aplicación de escritorio no aparecen en la versión web, o aparecen con el mensaje “Pendiente de sincronizar”.

## Pasos

1. Revisar que el equipo tenga conexión a internet.
2. En la aplicación de escritorio, abrir el menú “Herramientas” y elegir “Sincronizar ahora”.
3. Esperar a que el ícono de la nube, abajo a la derecha, se ponga verde.
4. Si sigue en rojo, cerrar la sesión de la aplicación de escritorio y volver a iniciarla.
5. Si las facturas siguen pendientes, revisar en “Herramientas”, “Registro de sincronización”, el código de error.

## Códigos de error frecuentes

- **S-01:** sin conexión. Repetir el paso 1.
- **S-02:** sesión vencida. Repetir el paso 4.
- **S-09:** conflicto de datos entre dos equipos. No se resuelve en el nivel 1: escalar a una persona con el código y la fecha de las facturas afectadas.
